# ultraplan 프롬프트

아래 내용을 복사해서 `/ultraplan` 뒤에 붙여 실행한다.
(이 프로젝트 폴더 안에서 Claude Code를 실행해야 git 인식됨)

---

폴리마켓 엣지 전략의 수익 가능성을 검증하는 드라이런(시뮬레이션) 트레이딩 봇을 설계해줘.
실제 돈·실제 주문 없이, 공개 API의 라이브 데이터로 "전략이 마찰비용을 넘는 엣지를 내는가"를 측정하는 게 목표.

[환경/제약]
- Windows 10, Python 3.13(`py` 명령), 한국어 주석·문서
- 공식 SDK는 Polymarket `py-sdk` 사용 (구버전 py-clob-client는 archived라 금지)
- 읽기: Gamma(마켓 탐색)/Data(과거)/CLOB(호가) + real-time-data-client(WebSocket) 개념
- 최소 구현, 불필요한 추상화·리팩토링 금지

[검증 대상 핵심 로직]
- 엣지 = (내 추정확률 − 시장가격). 엣지 > 임계값일 때만 "가상 매수"
- 유동성 필터: 거래량/스프레드 미달 마켓 제외
- 비용 모델 반영: 메이커 0%/테이커 수수료, 환전 왕복 ~3%, 본전 차익 ~3~5% 허들
- 포지션 사이징: 프랙셔널 켈리(¼) + 1회 베팅 상한
- 주문은 실제 전송 대신 "의도한 주문 + 시뮬 체결"로 로깅

[가장 중요 — 반드시 다룰 것]
- 엣지 신호를 어디서 얻는가. 후보: ①신규/저거래량 마켓 미스프라이싱 ②뉴스 반영 시차 ③카테고리 전문성.
  이 중 하나를 1차 테스트 대상으로 고르는 방안 포함
- 측정 지표: 시뮬 손익, 가격대비 승률(캘리브레이션), 실현 엣지, 조건충족 기회 수,
  마찰비용(3~5%) 돌파 여부 → 최종적으로 "가능/불가능" 판정

[산출물]
돌려볼 수 있는 시뮬레이션 + 의사결정 로그 + 가능성 리포트. 단계별 구현계획으로.
